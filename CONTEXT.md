# TrustVault v2 — Agent Context

> Read this before doing anything. Shared context for all agents working on this repo.

## What We're Building

**TrustVault** — an autonomous agent that builds portable, verifiable trust resumes using ERC-8004 onchain attestations. Agents query each other's trust profiles before cooperating. No central authority.

Submission for The Synthesis hackathon. Tracks: **Agents that Trust** (primary) + **Agents that Cooperate** (secondary).

## Core Flow

```
Agent A discovers Agent B via ERC-8004 agent card
    → queries B's trust resume (score, attestations, skills)
    → requests cooperation with task description + min trust threshold
    → Agent B evaluates: trust score meets threshold? skills match?
    → Agent B accepts or declines (with AI-enhanced reasoning via Venice)
    → if accepted, agents cooperate on the task
    → each agent issues attestation to the other post-cooperation
    → attestations update trust scores onchain via ERC-8004
```

## Stack

| Layer | Tech |
|-------|------|
| Runtime | Cloudflare Workers + Durable Objects |
| HTTP | Hono |
| Identity | ERC-8004 NFT on Base Sepolia |
| Reputation | ERC-8004 Reputation Registry |
| State | Durable Object (persistent agent memory) |
| Inference | Venice AI (no-data-retention) |
| Language | TypeScript (strict) |

## Key Innovation (vs v1 AgentClear)

- **Durable Objects** for persistent agent memory — survives cold starts
- **Trust Resume** as first-class concept — portable across platforms
- **Cooperation protocol** — agents evaluate trust before working together
- **No Docker** — edge-native, runs globally on Cloudflare
- **Bidirectional trust** — both agents query each other

## Judging Criteria

1. GET `/.well-known/agent-card.json` — valid ERC-8004 card with trust resume
2. Trust resume shows attestation history and computed score
3. Cooperation endpoint demonstrates trust-gated decision making
4. On-chain ERC-8004 registration verifiable
